# Saúde do Bronze · Site

Página institucional e de agendamento do [@saudedobronze](https://instagram.com/saudedobronze).
HTML, CSS e JS puros, sem build. Pronta para o GitHub Pages.

## Estrutura

- `index.html`: conteúdo da página (todas as seções)
- `styles.css`: visual (cores em `:root`)
- `script.js`: formulário que monta a mensagem e abre o WhatsApp
- `assets/`: logo e favicon

## Publicar no GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → escolha a branch e a pasta `/ (root)`.

## Pendências (placeholders)

Busque por `[placeholder` e `R$ XX` no `index.html`:

- Serviços e preços reais
- Horário de funcionamento
- Técnica de bronzeamento usada (FAQ). Não fazer promessas de saúde.
- Depoimentos reais (destaque "Feedbacks!" do Instagram)
- Fotos do espaço autorizadas pelo estabelecimento (as atuais são ilustrativas, do Unsplash)
- Números de prova social (avaliação, sessões realizadas)
- Confirmar cidade/bairro do endereço para o mapa
